# EnSys – Empathic AI Chatbot System

EnSys is an AI-powered empathic chatbot system developed for the food service industry to improve customer service interactions and feedback management. The system leverages Natural Language Processing (NLP), sentiment analysis, and empathic computing to understand customer emotions and provide personalized, human-like responses.

The project aims to address common customer service challenges such as delayed response times, limited feedback documentation, and inefficient follow-up processes. By integrating AI-driven communication, EnSys enhances customer satisfaction, operational efficiency, and feedback analysis.

---

## Key Features

* AI-powered empathic chatbot
* Sentiment analysis and emotion detection
* Real-time customer interaction
* Customer feedback collection and analysis
* FAQ assistance system
* Admin feedback reports and analytics
* User-friendly interface and navigation
* Personalized conversational responses
