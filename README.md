# EnSys
Customers can interact with the AI chatbot by scanning QR codes in the restaurant or accessing its URL. The web-based chatbot allows instant, seamless feedback and empathetic conversations about dining experiences. This user-friendly approach streamlines feedback and boosts customer engagement and satisfaction.

## 1. Home Page Overview
<img width="1920" height="1032" alt="01" src="https://github.com/user-attachments/assets/4462b0b2-e383-496f-b4a2-beff69fe5e24" />
At the top of the homepage, you will find the Top Navigation Bar. This bar provides quick access to the main features of the system. Here’s a breakdown of the features you will see:
EnSys: Displays a welcome message.
About: Learn more about the system and its purpose.
Features: Explore the various features available within the application.
FAQ: Find answers to frequently asked questions.
Report: Report issues or provide feedback.
Chat Now: Get real-time assistance from our chatbot.
